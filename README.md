# Guia de Ejercicios Fisicos

Bienvenido a esta guía donde encontrarás diferentes tipos de ejercicios físicos organizados para mejorar tu salud, resistencia y bienestar general.

## 📚 Índice de Ejercicios

Tipos de ejercicios:

- 🏃‍♂️ [Cardio](ejercicios/cardio.md) → Mejora la resistencia cardiovascular
- 💪 [Fuerza](ejercicios/fuerza.md) → Desarrollo muscular y potencia
- 🤸‍♂️ [Flexibilidad](ejercicios/flexibilidad.md) → Movilidad y elasticidad
- 🔄 [Entrenamiento Funcional](ejercicios/entrenamiento_funcional.md) → Movimientos del día a día
- 🧘 [Yoga](ejercicios/yoga.md) → Relajación y control mental
- 🧍‍♀️ [Pilates](ejercicios/pilates.md) → Core y postura
- 🚴 [Ciclismo](ejercicios/ciclismo.md) → Resistencia y cardio de bajo impacto
- 🏊‍♂️ [Natación](ejercicios/natacion.md) → Trabajo completo del cuerpo
- 🥊 [Boxeo](ejercicios/boxeo.md) → Coordinación y resistencia
- 🔥 [CrossFit](ejercicios/crossfit.md) → Alta intensidad y fuerza funcional


## 🎯 Objetivo del proyecto

Este proyecto tiene como objetivo practicar el uso de Git mediante la creación de ramas, commits y fusiones organizando una guía de ejercicios físicos.
